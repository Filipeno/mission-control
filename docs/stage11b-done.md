# Stage 11b done: helper questions and the daily digest on the phone (MC 0.14.0, 2026-11-18)

## What it does
- **Helper questions.** An open `QUESTION id=...` job from Gemini or Codex is a message `inbox\claude\*-question-<id>.md` plus a saved job `state\questions\<id>.json` (written by `ask.ps1`). mc-pc lists those (`pc/mc_digest.py questions`, re-read only when the inbox listing changes) and sends them as `questions` in every report. The Pi (`pi/ai_hub.py`, class AiHub) keeps them, shows them in `GET /api/claude` (`questions`) and raises one "Helper question waiting" notification per new id (remembered across restarts). The Claude tab shows a card per question (helper, question, shortened task, text box, "Send answer"; no fingerprint). `POST /api/claude/questions/<id>/answer {text}` -> state `sent`, PC inbox item `helper-answer` -> mc-pc runs `mc_digest.py answer`: checks the id and the saved job, starts `ask.ps1 -AnswerId <id> -Answer:<text>` detached (it re-runs the job and can take minutes), moves the inbox file to `inbox\claude\done\`, reports the result. The card then says "Answered". Answer length 1-1000 characters, whitespace collapsed; a second answer to the same question is ignored (`duplicate: true`). A start failure puts the card back to open with the error. A question that vanishes from the PC's list (answered elsewhere) turns "Answered" too; answered cards stay 24 h.
- **Daily digest.** Settings: `digest_on` (default on), `digest_time` (default 20:00, picker in the app's Settings, "Daily digest" card, plus "Send digest now"). From 30 min before the time the Pi sets `digest: true` in the command reply (at most every 15 min); mc-pc runs `mc_digest.py digest` and POSTs `/api/pc/digest`. The digest lists: tasks done today (lines dated today in `D:\projekty\*\WORKLOG.md`, `D:\projekty\WORKLOG.md`, `D:\Škola\WORKLOG.md` and `D:\Škola\*\WORKLOG.md`; only the last 96 KB of each file is read; the file list after the arrow is dropped), commits (`git log --branches` across `D:\projekty\*`, linked worktrees skipped) and release tags created today, and usage left from `usage.ps1 -Json` (Claude 5 h / weekly, Codex, Gemini app and Perplexity jobs left, parked helpers). At the set time (or up to 3 h later if the PC was off) the Pi adds "Waiting for you" (open to-dos, pending approvals, open helper questions: the Pi owns those), stores the Doc "Daily digest <date>" (Docs tab, Docs list) and sends one notification (summary + number waiting). Quiet hours make it silent; Mute and the Claude category switch apply. One digest per day; "Send now" does not use that up.
- Deviation from the brief: the "waiting for Filip" section is built on the Pi, not by mc-pc, because the phone state (to-dos, approvals, questions) lives there.
