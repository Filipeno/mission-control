# Test Mission Control 0.14.0 (helper questions + daily digest)

Install 0.14.0 (Settings > Check for updates). mc-pc was restarted on the PC with the release.

- [ ] Claude tab: if a helper (Codex/Gemini) has an open question, a card "CODEX ASKS" (or Gemini) shows the question, a short task line (tap it to expand), a text box and "Send answer". The old Codex test-run question from last night may still be there.
- [ ] Type an answer and tap "Send answer": a toast "Answer sent", the card says "Sending..." and within a minute "Answered". On the PC the question file moved to `D:\ai-hub\inbox\claude\done\`. (This re-runs the helper's job, so pick a question you really want to answer.)
- [ ] A new helper question gives one notification "Helper question waiting" (not repeated for the same question).
- [ ] Settings > Daily digest: switch, time picker, "Send digest now". Tap "Send digest now": within about a minute a notification "Daily digest" arrives (silent between 22:00 and 07:00) with a line like "3 done, 5 commits, 2 releases, used: 5h 61%...".
- [ ] Docs tab > Docs: a doc "Daily digest <date>" with Done today, Commits, Releases, Usage left and Waiting for you.
- [ ] Tomorrow evening at 20:00 (or the time you set) the digest arrives by itself, only once.
